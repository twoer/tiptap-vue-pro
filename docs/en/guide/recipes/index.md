# Business Recipes

Recipes are business-oriented integration guides. They are not API inventories; they answer the more practical question: “How do I put this editor into a real admin workflow?”

If you have not installed a package yet, start with [Quick Start](/en/guide/quick-start). For the full prop reference, see [Props](/en/api/props).

## Recommended order

1. [Admin Rich Text Form](/en/guide/recipes/business-editor-form)
   The most common article, announcement, product-description, and help-center form.

2. [Autosave + Local Drafts](/en/guide/recipes/autosave-drafts)
   For long-form content and workflows where losing edits is expensive.

3. [Image, Video, and Attachment Uploads](/en/guide/recipes/uploads)
   Move from local mock uploads to a production backend, OSS, COS, S3, or CDN.

4. [Readonly Preview and Detail Pages](/en/guide/recipes/readonly-preview)
   Reuse the same content in edit, preview, and detail modes.
